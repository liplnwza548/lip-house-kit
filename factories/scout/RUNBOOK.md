# โรงส่องฟุต (Scout) — RUNBOOK: จากฟุตดิบเป็นใบสั่งตัด

โรงนี้เป็นงานครึ่งคนครึ่งเครื่อง: เครื่องเตรียมหลักฐาน (สคริปต์)
คน/เอเจนต์ตัดสิน (ดูภาพ) — ห้ามสลับหน้าที่กัน

## ขั้นเครื่อง (รันสคริปต์)

  python factories/scout/make_contact.py ฟุต.mp4 scout_out/

ได้ 3 อย่าง: contact.jpg (ภาพรวมทุกวิ) + metrics.csv (ชัด/สว่าง/ไหวต่อวิ)
+ shot_table.csv (โครงเปล่าไว้เติม)

## ขั้นคน (ดูแล้วให้เกรด)

1. เปิด contact.jpg เทียบ metrics.csv ช่วงที่นิ่ง+ชัด (sharp สูง + motion ต่ำ)
2. เติม shot_table.csv: ทุกแถวต้องมี start/end/grade(A/B/C)/role/hook หรือไม่/note
3. เกรด A = ใช้ได้เลย · B = ใช้ได้ถ้าจำเป็น/ต้องซ่อม (stabilize) · C = ทิ้ง (ย้ายมุม/หลุดโฟกัส/กระแทก)
4. เลือก hook 2-3 ตัว (นิ่งสุด/ชัดสุด/เห็นสินค้าเต็ม) พร้อมเวลาชัดเจน

## ออกใบสั่งตัด (edit order JSON)

ตัวอย่าง `edit-order.json` (โรงประกอบอ่านไฟล์นี้):

```json
{
  "version": 1,
  "hook": {"file": "H03_rounded_reveal.mp4"},
  "proxy": "proxy30.mp4",
  "target_dur": 30.0,
  "shots": [
    {"id": "NC4", "ss": 4.5, "d": 1.8, "note": "TURN opener"},
    {"id": "BC04r", "ss": 19.0, "d": 2.5, "note": "FRONT"}
  ]
}
```

กฎ: ผลรวม hook + shots ต้องเท่า target_dur (pipeline ตรวจให้)
ห้ามสั่งช็อตเกรด C · ช็อต B ต้องเขียนว่าซ่อมอะไรใน note

## ประตูตรวจก่อนส่งโรงประกอบ

- shot_table ครบทุกแถว ไม่มีช่องว่างเวลาโดยไม่มีคำอธิบาย
- hook มีอย่างน้อย 1 ตัวพร้อมเหตุผล
- เกรด B ทุกตัวมีแผนซ่อมใน note
